# NBYS 激光精准靶

本目录中的 A4、A3 靶纸为 NBYS 自有设计。四角定位标记采用“黑色外框、白色隔离环、黑色中心块”三级结构，不依赖彩色打印，供 Android 靶机自动定位和透视校正使用。

## 打印要求

- 使用 `100%` 或“实际大小”打印，禁止“适合页面”缩放。
- 使用哑光白纸，避免覆膜和强反光。
- 四个定位标记必须完整保留，不能被胶带、夹具或弹孔遮挡。
- 手机侧放时，四个标记都需要进入最终放大后的画面。
- A4 和 A3 使用相同识别结构，只是物理尺寸不同。

## 文件

- `nbys-laser-precision-a4.pdf`：A4 规格。
- `nbys-laser-precision-a3.pdf`：A3 规格。
- `nbys-human-silhouette-a4.pdf`：A4 人形轮廓靶。
- `nbys-human-silhouette-a3.pdf`：A3 人形轮廓靶。
- `nbys-laser-precision-*-preview.png`：快速预览，不用于打印。
- `nbys-human-silhouette-*-preview.png`：人形靶快速预览，不用于打印。

人形靶直接裁切自用户提供的 `b3-150.png` 左侧人形靶区域，未重新绘制轮廓；右侧说明区被移除，四角增加了 NBYS 黑白定位标记。
