# 激光训练屋 UX 原型说明

## 评审范围

本目录是独立产品原型，不修改正式 H5、后端、数据库或 Android 业务代码。所有写操作只在浏览器内模拟。

### H5

- 正式队员训练屋首页、完整历史成绩和训练详情。
- 单人/多人选择、创建/加入房间、房间列表。
- 房主数据看板与设置、加入者只读看板的交互方向。
- 本人/全部数据切换、最多 3 靶机实时状态和命中流。
- 准备语音、随机延迟、蜂鸣、训练占用、设备离线和自动结束结果。
- 非正式队员继续显示通知的对照页面。

### Android

- 会员登录、选择房间和 1-3 号靶机位。
- 摄像头、Precision 靶纸 Overlay、命中标记和采集指标。
- 自动校准、手动四点、自动对焦、激光校准、清空和设置。
- READY、校准中、训练中、校准失败、低 FPS 和断线补传状态。

### 后管

- 房间、设备、模式、成绩和审计管理。
- 强制关闭房间、断开/停用设备、修改/删除成绩的确认流程。
- 原始成绩与修改值对照，业务删除说明和审计记录。

## 视觉与组件规则

- H5 延续现有深色战术风格，荧光绿只用于当前状态和主要操作。
- Android 使用摄像头优先的工具界面，训练状态始终不遮挡靶纸主体。
- 后管采用浅色密集工作台，列表和筛选优先，不使用营销式大卡片。
- 卡片圆角不超过 6px；所有固定网格使用稳定列宽，动态内容不改变布局。
- 设备状态统一使用 READY、OFFLINE、LIVE、CALIBRATING 等词，并配中文说明。

## 正式实施清单

1. 冻结房间、轮次、靶机和命中事件状态机。
2. 冻结 REST 与 WebSocket 协议、错误码和版本字段。
3. 建立独立 training-center 服务与数据库迁移。
4. 实现 H5 导航分流、训练历史、房间与实时看板。
5. 实现后管房间、设备、模式、成绩和审计模块。
6. 新建 Kotlin Android 工程，实现相机、校准、识别和可靠上传。
7. 按单靶、三靶、断线恢复和多人轮流训练进行三端联调。

## 待确认

- H5 首页历史记录密度与成绩详情布局。
- 多人房间列表和房主设置的操作层级。
- 三靶实时看板在 390px 宽度下的信息量。
- Android 摄像头工具按钮与手动四点交互。
- 后管成绩修改/删除及审计信息是否满足运营需要。
